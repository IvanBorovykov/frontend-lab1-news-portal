## Запуск

Відкрийте `index.html` у браузері. Збирання та встановлення залежностей не потрібні. Для завантаження ілюстративних зображень із Picsum потрібен інтернет.

Використано лише HTML5 та окремий SVG-логотип. CSS, JavaScript, бібліотек і фреймворків немає. Видимий текст та документація українською. Назви файлів і технічні атрибути залишено латиницею.

Новини, біографія редактора та контакти вигадані. Форма демонструє розмітку та вбудовану перевірку браузера. `action="#" method="post"` відповідає завданню, але серверного обробника немає: кнопка «Надіслати» не доставляє повідомлення, а POST може завершитися помилкою на статичному сервері. «Очистити» скидає поля.

## Об'єднані клітинки таблиці

У таблиці вісім об'єднаних клітинок:

- Заголовки «Відділ», «Джерело інформації», «Тема»: кожен має `rowspan="2"`.
- Заголовок «Працівник»: `colspan="2"` над ім'ям та посадою.
- Відділи «Міські новини», «Культура», «Економіка»: кожен має `rowspan="2"`.
- Підсумковий заголовок: `colspan="4"`, поруч окрема клітинка з кількістю працівників.

Кожен рядок з урахуванням об'єднань займає п'ять стовпців.
